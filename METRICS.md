# Product metrics

`npm run metrics` reports non-QA unique users, successful and no-result search events, operator-type users, comparison users, copiers, official-source openers, and returning comparison users. Seven-day searcher and copier counts show early movement.

A successful search is emitted only when a local normalized query returns at least one public unit. No query, station, operator, route, code, or coordinate enters telemetry.
